# Module Inventory

Statuses describe repository evidence, not deployment readiness. **Implemented** means application/schema code and a corresponding test exist. **Partial** means material workflow scope is still missing. **Planned** means no substantial implementation/test exists. **Unverified** means repository code exists but has not been exercised against a live Supabase project. A module may be Implemented or Partial and still be operationally Unverified; no module is marked verified.
